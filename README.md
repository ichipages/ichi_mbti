# 16タイプ性格診断

4つの軸（E/I・S/N・T/F・J/P）を測る、ブラウザだけで動く性格診断です。

**▶ https://hellohello334.github.io/ichi_mbti/**

## 特徴

- **全84〜104問（所要15〜20分）** — 基本60問、判定が割れた軸のみ追加0〜20問、心理機能24問の3段階
- **軸を5つの側面に分けて測定** — 同じ「内向型」でも、側面ごとに向きが違うことが見える
- **2つの測り方を突き合わせ** — 4軸の集計と心理機能の集計から、タイプごとの確率を算出
- **回答品質のチェック** — 言い換え質問ペアの一貫性、同意バイアス、同一選択肢率を検出
- **16タイプすべてにオリジナルのイラスト** — 相性タイプや候補タイプも、押すと概要が開く

## 構成

単一のHTMLファイルです。ビルド不要、サーバー不要、外部通信はGoogle Fontsのみ。回答データはブラウザの外に出ません。

```
index.html   診断本体
ogp.png      SNS共有用の画像
```

## 注意

この診断は公式のMBTI®検査ではなく、同じ4つの軸を測るオリジナルの診断です。MBTI®はThe Myers-Briggs Company（および国内ではMBTI協会）の登録商標です。

結果に表示される日本での割合は、16Personalities日本ユーザーの公開データに基づく概数です。受検者に偏りがあるため、国民全体の分布ではありません。

性格は状況や時期によって変わります。結果は自分を決めつける枠ではなく、考えるきっかけとして受け取ってください。
